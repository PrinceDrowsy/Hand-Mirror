# Examples

Cardinal projects that change the character creator. Build and install one with `Cardinal.exe build PROJECT.json --install`.

- `HiddenParts.json` unlocks the parts the game ships but doesn't offer.
- `NewParts.json` adds a new pupil and a new eyebrow with Cardinal's `new part` template.

Both change the same creator files, so install one at a time, or merge them with `Cardinal.exe merge`.
